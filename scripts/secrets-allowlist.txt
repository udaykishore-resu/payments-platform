# scripts/secrets-allowlist.txt — justified exemptions for scripts/check-secrets.sh.
#
# Format, one per line:
#
#   <sha256-hex>          # why this literal is not a secret
#   path:<glob>           # why every finding under this path is not a secret
#
# The value is HASHED rather than written out. Two reasons, and the second is the one that
# matters: a list of literal card numbers is itself a file full of card numbers, and a
# hash forces each exemption to name one specific value instead of a pattern that quietly
# widens over time. Get the digest with:
#
#   scripts/check-secrets.sh --hash '4111111111111111'
#
# A `path:` entry is a blunt instrument and needs a correspondingly strong reason. Prefer a
# hash. Never add `path:internal/**` or anything else that covers code a person edits.
#
# Every entry must carry a reason after `#`. An entry without one fails S5 — an unexplained
# exemption is indistinguishable from an accident, and this file is the first place someone
# will try to silence a true finding.
#
